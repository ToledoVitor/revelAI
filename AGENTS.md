# RevelAI agent guide

## Repository

- Use `pnpm` for JavaScript and TypeScript workspace commands.
- Prefix shell commands with `rtk`.
- Keep product behavior aligned with `CONTEXT.md` and accepted ADRs.
- Keep secrets out of clients, fixtures, logs, commits, and generated artifacts.
- Prefer public-behavior tests at package or application boundaries.
